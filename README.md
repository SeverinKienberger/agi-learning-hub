# AGI Learning Hub

## Beschreibung

Ein Learning Hub zum Lernen mit SAP-Kursen, bestehend aus Units und Chapters. Jede Unit hat einen zugehörigen Test.
Tests werden automatisch ausgewertet, falsche sowie richtige Antworten werden angezeigt.

Lernpfade gruppieren mehrere Kurse.
Lernpfade und Kurse können gefiltert und durchsucht werden.

Die Seite hat noch keine Landing-Page.

Das Projekt entstand im Rahmen meines Praktikums bei AGILITA AG und diente als Lernprojekt.

## Technologien

* SAPUI5 (JavaScript Framework, MVC)

## Mockdaten

Mockdaten wurden mit ChatGPT basierend auf einer vorgegebenen Datenstruktur generiert.

## Hinweis

Funktionalitäten wie „My Learning“, Badges und Certificates sind aktuell nicht implementiert.

## Setup

Um das Projekt lokal zu starten:

| :exclamation:  funktioniert mit node.js Version v22.23.5. andere Versionen können Probleme verursachen |
|----------------------------------------------|

1. 'main' branch clonen
2. Folgende Befehle in der Konsole im Projektordner ausführen

```Bash
npm install
npm start
```
